## Repository Structure

Each file focuses on **one core concept**.

Examples:
- `hello.py` – basic output
- `data-types.py` – Python data types
- `for_loops.py` – loop constructs
- `while_loop.py` – while loop usage
- `ifelse_prob1.py` – conditional logic
- `evenodd.py` – basic problem solving
- `tableof56.py` – loop + arithmetic practice

Files are kept simple and executable to reinforce fundamentals.

---

## Daily Rule System

- Every day must produce **at least one visible output**
- Output can be:
  - A Python script
  - Solved practice problems
  - Refactored or improved code
- No output = failed day (regardless of time spent)
